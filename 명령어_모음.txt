==========================================================
 2. Claude Code 실행 옵션
==========================================================

claude              새 대화 시작
claude -c           직전 대화 바로 이어서 하기
claude -r           예전 대화 목록에서 골라서 이어가기   <- 제일 유용


  ---- 대화 목록 (Claude 앱의 프로젝트 대화 목록과 같은 것) ----

  claude -r        PowerShell에서 목록 띄우기
  /resume          Claude Code 안에서 목록 띄우기

  * 날짜 / 메시지 수 / 첫 메시지가 목록에 표시됨
  * 방향키로 고르고 엔터
  * 실행한 폴더 기준으로 나뉨 -> 다른 프로젝트 대화가 안 섞임


  ---- 요령: 제목을 직접 못 다니까 첫 메시지를 제목처럼 쓸 것 ----

  나쁜 예)  계속 하자
            -> 나중에 목록에서 뭐가 뭔지 모름

  좋은 예)  [Phase 2] 부착물 시스템 - AttachmentSocket 위치 조정
            [Phase 3] WarFX 탄흔 - 벽에 구멍 안 생기는 문제
            [버그] AK105 조준할 때 손 위치 틀어짐


==========================================================
 3. Claude Code 안에서 쓰는 명령 (/ 로 시작)
==========================================================

/resume             예전 대화 목록에서 골라 이어가기
/compact            대화를 요약해서 압축          <- 같은 작업 계속할 때
/clear              대화 비우고 새로 시작         <- 다른 작업으로 넘어갈 때
/status             사용량 / 연결 상태 확인
/cost               이번 세션에서 쓴 양
/mcp                Unity 연결됐는지 확인
/help               도움말
/exit               종료  (또는 Ctrl+C 두 번)


  ---- /clear 와 /compact 구분 ----

  /compact    대화 요약해서 압축. 맥락은 유지되고 사용량만 줄어듦
              -> Phase 2 하다가 대화가 길어졌을 때

  /clear      대화를 완전히 비움
              -> Phase 2 다 끝나고 Phase 3 시작할 때


  ---- /clear 해도 안 없어지는 것 (중요) ----

  CLAUDE.md              안전. 매번 자동으로 다시 읽음
  코드 / Unity 작업물     안전. 디스크에 저장돼 있음
  예전 대화 기록          안전. claude -r 로 다시 꺼낼 수 있음

  * /clear 는 삭제가 아니라 "이제부터 새 얘기 하자"에 가까움
  * 다만 "방금 뭘 하고 있었는지"는 잊어버림


  ---- /clear 하기 전 습관 ----

  1) 지우기 직전에 이렇게 치기:
       지금까지 한 것과 다음에 할 것을 진행상황.md에 정리해서 저장해줘

  2) /clear 후 새 대화에서:
       진행상황.md 읽고 이어서 하자


==========================================================
 4. 허락 창 뜨면? (Do you want to proceed?)
==========================================================

  선택지
    1. Yes                        이번 한 번만 허락
    2. Yes, and don't ask again   앞으로 안 물어봄
    3. No                         거부


  ---- 2번 눌러도 되는 것 ----

  [읽기]  Get / Read / List / Find / Status / Console / Capture / Search
          -> 정보만 가져옴. 아무것도 안 바뀜

  [작업]  Create / Add / Set / Attach / Instantiate / Save / Recompile
          -> 이게 게임 제작 그 자체. Unity에서 Ctrl+Z로 되돌릴 수 있음


  ---- 반드시 1번, 내용 읽고 판단 ----

  Delete Asset          파일 삭제
  Delete GameObject     오브젝트 삭제
  Remove Component      컴포넌트 제거
  Clear Baked Lighting  구운 조명 데이터 날림
  Clear NavMesh         구운 길찾기 데이터 날림
  Unpack Prefab         프리팹 연결 끊김
  Switch Build Target   전체 재임포트. 수십 분 걸림
  Package Remove        패키지 제거

  * "이거 왜 지우려는 거지?" 싶으면 3번(No) 누르고 이유를 물어볼 것

 5. Unity CLI (PowerShell에서 직접 실행)
==========================================================

  * 보통은 안 씀. Claude Code가 알아서 함
  * 뭔가 이상할 때 직접 확인용

unity status                       Unity 에디터 연결 확인
unity list                         쓸 수 있는 명령 전체 보기
unity doctor                       CLI 상태 진단
unity auth status                  로그인 상태 확인
unity editors -i                   설치된 에디터 목록

unity command console --tail 50    Unity 콘솔 로그 50줄 보기
unity command eval --code "..."    C# 코드 즉시 실행


==========================================================
 6. 문제 생겼을 때
==========================================================

  ● Unity 연결이 안 될 때
      1) Unity 에디터가 켜져 있는지 확인
      2) PowerShell에서  unity status
         -> "ready" 안 나오면 Unity 껐다 켜기
      3) Claude Code에서  /mcp

  ● claude 명령을 못 찾을 때
      PowerShell 창을 닫고 새로 열기

  ● 사용량 한도에 걸렸을 때
      5시간마다 리셋됨. 주 단위 한도도 있음
      -> /clear 자주 쓰면 한도를 훨씬 오래 씀

  ● Unity 콘솔에 빨간 에러가 뜰 때
      Claude Code에 그냥 이렇게 치면 됨:
      "Unity 콘솔 에러 확인하고 고쳐줘"
